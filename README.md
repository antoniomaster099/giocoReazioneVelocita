# giocoReazioneVelocita

## Scopo
Piccolo gioco programmato in Arduino.
Progetto personale per scopi di studio autodidattico.
Il suo obiettivo è il semplice intrattenimento.
Una volta avviato Arduino, 3 LED (rosso, giallo, verde) si attiveranno in una sequenza randomica.
L'utente ha come obiettivo quello di premere il pulsante non appena si accende il LED verde.

## Materiali
* 1x Arduino UNO R4 WiFi
* 4x Cavi maschio-femmina
* 7x Cavi maschio-maschio
* 1x I2C LCD 1602
* 3x Resistenza 200Ω
* 1x Small button (pulsante)
* 3x LED (rosso, giallo, verde)

## Librerie utilizzate
* Wire
* LiquidCrystal_I2C (di Frank de Brabander)
